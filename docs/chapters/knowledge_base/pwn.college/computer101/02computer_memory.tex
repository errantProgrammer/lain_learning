\subsection{Loading From Memory}\label{subsec:loading_from_memory}

La memoria al ser un lugar muy grande, esta se almacena de forma
secuencial, por lo tanto cuando realizamos lo siguiente:

\begin{codebox}[ASM]{}
	mov rdi, 31337
\end{codebox}

En este caso, almacenamos el valor de 31337 en el registro de \mintinline{asm}{rdi}.

Pero si queremos saber el valor del registro \mintinline{asm}{31337}:

\begin{codebox}[ASM]{}
	mov rdi, [31337]
\end{codebox}

Entonces, aquí estamos moviendo el valor del registro \mintinline{asm}{31337} al valor de \mintinline{asm}{rdi}.

\subsection{Dereferencing Yourself}\label{subsec:dereferencing_yourself}

Podemos realizar la desreferencia, de un registro en el mismo registro.

\begin{codebox}[ASM]{}
	mov rdi, [rdi]
\end{codebox}

\subsection{Dereferencing with Offsets}\label{subsec:dereferencing_with_offsets}

El valor de \mintinline{asm}{[rdi]}, es el valor de un registro de la memoria. Por lo tanto,
se puede realizar un aumento, para poder buscar un valor adicional.

\begin{codebox}[ASM]{}
	mov rdi, [rdi + 8]
\end{codebox}
